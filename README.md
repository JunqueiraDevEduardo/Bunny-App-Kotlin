# Together App Kotlin (TOGETHER) 🐰💖🐱

Bichinho virtual adorável e jogo 3D multiplayer em Machu Picchu desenvolvido em Kotlin puro para Android.

## Estrutura do Projeto
- **`Together/`**: Projeto Android principal pronto para abrir no Android Studio.
  - **`app/`**: Código-fonte nativo em Kotlin, interface em Canvas 2D, CatBunnyCraft 3D e sintetizador de som procedural `SoundFx`.
  - **`build.gradle.kts`**, **`settings.gradle.kts`**: Configurações Gradle com `rootProject.name = "Together"`.

## Como Executar
1. Abre o **Android Studio**.
2. Seleciona **File > Open** e escolhe a pasta **`Together`** (ou `Bunny App Kotlin/Together`).
3. Clica em **Sync Project with Gradle Files** e executa no emulador ou dispositivo físico via **Run ▶**.
